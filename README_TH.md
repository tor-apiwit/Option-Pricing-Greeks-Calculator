# แพ็กเกจคำนวณราคาออปชันและโครงสร้างหุ้นกู้ (Option Pricing & Structuring Package)

โปรเจกต์นี้ถูกแยกโครงสร้างมาจากไฟล์ Colab ต้นฉบับ (`option_pricing___greeks_calculator.py`) เพื่อจัดระเบียบใหม่ให้เป็นแพ็กเกจ Python ตามมาตรฐานการพัฒนาซอฟต์แวร์

## โครงสร้างไฟล์
```text
option_pricing_pkg/
├── __init__.py       # รวบรวมและเปิดเผยฟังก์ชันสาธารณะทั้งหมด
├── models.py         # โมเดลคำนวณ (Black-Scholes, Monte Carlo, Binomial Tree)
├── greeks.py         # คำนวณค่าความเสี่ยง (Greeks) ด้วยวิธี FDM และ Closed-form
├── reports.py        # สร้างรายงานเปรียบเทียบ
├── structuring.py    # ฟังก์ชันจำลองโครงสร้างหุ้นกู้ที่มีอนุพันธ์แฝง
└── main.py           # สคริปต์หลักสำหรับทดสอบและรันตัวอย่าง
```

## การติดตั้ง
ติดตั้งไลบรารีที่จำเป็นผ่านคำสั่ง:
```bash
pip install -r requirements.txt
```

## การใช้งาน
คำสั่งสำหรับการรันตัวอย่างที่จัดเตรียมไว้:
```bash
python -m option_pricing_pkg.main
```

ตัวอย่างการเรียกใช้งานฟังก์ชันในโค้ดของคุณ:
```python
from option_pricing_pkg import black_scholes_price
price = black_scholes_price(S=100, K=99, T=1, r=0.03, sigma=0.25, option_type="call")
```

## ข้อควรระวังเชิงเทคนิค (Critical Technical Debt)
*โปรดตรวจสอบและรับทราบปัญหาที่ติดมากับโค้ดต้นฉบับเหล่านี้ ก่อนนำไปใช้งานจริง:*

1. **สมการ Binomial Tree ผิดพลาด**: ฟังก์ชัน `binomial_tree_price()` มีการคำนวณปัจจัย Up/Down ผิดพลาดโดยนำไปลบ 1 (`u = np.exp(...) - 1`) ซึ่งขัดกับหลักการพื้นฐานทางการเงิน ทำให้ผลลัพธ์ Gamma และ Vega มีความคลาดเคลื่อนสูง
2. **ข้อจำกัดของสภาพแวดล้อม**: ฟังก์ชัน `price_report_with_vanilla()` ใช้คำสั่ง `display()` ซึ่งจะทำให้เกิด `NameError` ทันทีหากไม่ได้รันโค้ดผ่าน Jupyter Notebook หรือ IPython
3. **หน่วยตัวแปรไม่สอดคล้องกัน (Unit Mismatch)**: ตัวแปรใน `main.py` กำหนดเวลา $T=10$ (รูปแบบรายปี) แต่อัตราดอกเบี้ยและความผันผวนกลับถูกนำไปหาร 12 เพื่อให้เป็นรายเดือน ทำให้การคำนวณค่าบิดเบือน
4. **ไลบรารีส่วนเกิน**: โมดูล `models.py` มีการนำเข้าไลบรารี `yfinance` แต่ไม่มีการใช้งานจริง ทำให้เป็นการบังคับผู้ใช้ติดตั้ง Dependency โดยไม่จำเป็น
